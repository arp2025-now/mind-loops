# 🔁 Mind Loops > מערכת יומית לשינוי דפוסי חשיבה ובניית זהות עצמית דרך מיקרו־אימונים של 5 דקות. **הבטחת הערך:** _"במקום להבין את עצמך יותר — תתחילי לפעול כמו הגרסה שאת רוצה להיות, ב־5 דקות ביום."_ --- ## הבעיה שהמוצר פותר אנשים (בעיקר עצמאיים ויזמים): - יודעים מה הם צריכים לעשות - אבל נתקעים בגלל ספק עצמי, השוואות ודחיינות - צורכים תוכן — אבל לא משנים התנהגות Mind Loops הופך תובנה לפעולה: אימון מנטלי קצר שמייצר שינוי התנהגותי אמיתי. --- ## מה יש ב-MVP הזה מסך יומי אחד (**Daily Reset**) עם זרימה של 5 שלבים: 1. **זיהוי דפוס** — מה הדפוס שהיום עצר אותי? (בחירה מהירה או טקסט חופשי) 2. **ניתוח הלופ** — טריגר → מחשבה → פעולה 3. **שבירת זהות** — איך הגרסה הבטוחה בעצמי הייתה פועלת? 4. **פעולה אחת** — מה אני עושה היום בפועל? 5. **חיזוק זהות** — משפט מתחלף ("אני פועלת גם בלי ודאות" וכו') ### הפיצ'ר שמבדל — Pattern Tracker 🎯 האפליקציה מזהה אוטומטית חזרתיות ומציגה את **Top 3 הדפוסים שמנהלים אותך השבוע**. זה מה שהופך את זה מכלי כתיבה ל**מערכת שינוי התנהגות**. ### 🙏 הכרת תודה (Gratitude) רישום יומי של דברים שאת אסירת תודה עליהם — 3 שדות עם רמזים מתחלפים, רצף ימים, ו**קיר הכרת תודה** שמציג את כל מה שכתבת כפתקים מוצמדים. ### 🔔 תזכורת יומית בחירת שעה קבועה לאימון. בזמן שנקבע נשלחת **התראת דפדפן** (Notifications API) — ואם ההתראות חסומות, מוצגת תזכורת בתוך האפליקציה. > הערה: בגרסת ה-MVP התזכורת פועלת כל עוד הדפדפן/הטאב פתוח. תזכורת אמיתית > בכל מצב (גם כשהאפליקציה סגורה) דורשת backend עם Web Push — ראי "צעדים הבאים". ### ⭐ הזהות שלי (כוכב צפון) בהתחלה מגדירים את מי רוצים להיות, וזה הופך ל"כוכב צפון" שחוזר במסך היומי ובחגיגות הסיום. ניתן לעריכה בכל רגע. ### 🎯 מיקרו-אתגר אוטומטי כשדפוס חוזר 3 פעמים, האפליקציה מציעה אתגר ממוקד של 3 ימים לשבירתו — כך המעקב הופך ל**התערבות**, לא רק תיעוד. ### 🎉 חגיגת סיום בסיום ה-Daily Reset (או מיקרו-אתגר) קופצת אנימציית קונפטי + כרטיס עידוד. ### 🗣️ פנייה מותאמת מגדר בחירה בין נקבה / זכר / ניטרלי — כל הטקסטים מתאימים את עצמם. ### 📅 סנכרון ליומן מחלון התזכורת אפשר להוסיף אירוע יומי חוזר ל-**Google Calendar** או להוריד **קובץ .ics** (אפל/אאוטלוק) — וכך מקבלים תזכורת קופצת גם כשהאפליקציה סגורה, בלי שרת. ### פיצ'רים נוספים (V1) - ✅ **Login** (מבוסס שם + אימייל, נשמר מקומית) - ✅ **Daily Flow** בן 5 שלבים עם progress bar וולידציה - ✅ **היסטוריה** מלאה של כל התרגולים - ✅ **Pattern Tracker** — שבועי + כל הזמנים - ✅ **Weekly Summary אוטומטי** — הדפוס הכי חזק, כמה ימים תרגלת, מה השתנה בפעולה - ✅ **Streak** — ספירת ימים רצופים 🔥 - ✅ סימון "ביצעתי את הפעולה" + אחוז ביצוע --- ## 📱 PWA — התקנה למסך הבית האפליקציה היא **Progressive Web App**: אפשר להתקין אותה לנייד/למחשב, היא עובדת **offline**, וההתראות מוצגות דרך **Service Worker**. - **בנייד (Chrome/Android):** תפריט ⋮ → "הוספה למסך הבית" - **באייפון (Safari):** שיתוף → "הוספה למסך הבית" - **במחשב (Chrome/Edge):** אייקון ההתקנה בשורת הכתובת > ה-Service Worker וההתקנה דורשים הגשה דרך `http(s)` (localhost נחשב מאובטח). > בפתיחה ישירה של `file://` האפליקציה עובדת, אך ללא SW/התקנה. ## הרצה זוהי אפליקציית web ללא תלות וללא backend — כל הנתונים נשמרים ב-`localStorage` של הדפדפן. **אופציה 1 — שרת מקומי (מומלץ, מפעיל גם PWA/התראות):** ```bash cd mind-loop-os python3 -m http.server 8000 # גלשי אל http://localhost:8000 ``` **אופציה 2 — פתיחה ישירה:** ``` פתחי את index.html בדפדפן (ללא Service Worker). ``` --- ## מבנה הקבצים ``` mind-loop-os/ ├── index.html # מבנה + תבניות (templates) לכל המסכים ├── styles.css # עיצוב RTL בהיר וחם ├── app.js # כל הלוגיקה: auth, daily flow, gratitude, tracker, reminder ├── manifest.webmanifest # הגדרות ה-PWA (שם, אייקונים, צבעים) ├── service-worker.js # offline cache + הצגת התראות תזכורת ├── icons/ # אייקוני האפליקציה (192/512) ├── screenshots/ # צילומי מסך └── README.md ``` --- ## מודל הנתונים (localStorage) ```js // mlos.session -> אימייל המשתמש המחובר // mlos.user. -> אובייקט משתמש: { email, name, createdAt, entries: [ { date: "2026-05-29", pattern: "השוואה לאחרים", trigger, thought, oldAction, // הלופ identityAction, // שבירת זהות oneAction, // הפעולה להיום affirmation, // משפט החיזוק completed: true, actionDone: false } ] } ``` --- ## הצעדים הבאים (אחרי MVP) - Backend אמיתי + אימות (כדי לסנכרן בין מכשירים) - תזכורת אמיתית בכל מצב — Web Push (Service Worker + VAPID) או אימייל - ניתוח דפוסים מתקדם יותר (NLP על טקסט חופשי) - מסלולי אתגר (7 / 30 ימים) - שיתוף הישגים --- _MVP — נבנה כדי לבדוק את ההנחה: שינוי התנהגות יומי קצר > עוד תוכן._
